# ⚡ C Programming & Data Structures Architecture

### Modüler C Mimarisi: Dinamik Bellek Yönetimi ve Algoritmik Veri Yapıları

Bu depo; Fatih Sultan Mehmet Vakıf Üniversitesi Bilgisayar Mühendisliği lisans programı kapsamında geliştirilen modüler C projesini, Makefile derleme otomasyonunu ve teknik proje raporunu barındırmaktadır.

---

## 🛠️ Modül ve Dosya Hiyerarşisi

| Dosya                       | Açıklama                                                                               |
| :-------------------------- | :------------------------------------------------------------------------------------- |
| **`main.c`**                | Program giriş noktası, argüman ayrıştırma ve sistem akış denetleyicisi.                |
| **`Proje1.c` / `Proje1.h`** | Çekirdek veri yapıları, bellek tahsis/serbest bırakma ve algoritmik implementasyonlar. |
| **`makefile`**              | GCC tabanlı optimizasyonlu derleme ve linkleme otomasyonu.                             |
| **`korumali_rapor/`**       | Proje mimarisi ve analizlerini içeren filigranlı teknik dokümantasyon.                 |

---

## ⚙️ Derleme ve Çalıştırma

Projeyi GCC ve Make araçlarıyla yerel ortamda derlemek için:

```bash
make
./program.exe
```
